# Brand font

The landing page's display typeface is **Neue Kaine** (`--font-kaine` via `next/font/local` in `app/layout.tsx`).

The local font file is configured at:

```
public/fonts/neue-kaine-variable.ttf
```

It is loaded dynamically with fallback to system fonts, defining the `--font-kaine` CSS variable for brand elements.
